# §12 `StereoIPD=3.4` hypothesis: the public UE1 scale is ~44.6 UU/m, not 52.5 — start at ~2.85 UU

Filed by: `/gr`, 2026-09-02
Topic: `external-research/topics/2026-09-02-ue1-world-scale-is-nearer-45-uu-per-metre-than-52-5.md`
Dossier section: §12 ("World scale / IPD units … assumes ~52.5 UU per metre `[hypothesis]`")

The Unreal Wiki's own per-generation table `[reported 2026-09-02]`: **Unreal/UT99 = 13.6 UU/ft = 44.6 UU/m** (from the 78-UU player collision height); UT2003/2004 = 50.3 UU/m; the "52.5 UU/m / 16 UU per foot" rule is the folk constant the *newer* UT games sit closest to. So 64 mm ≈ **2.85 UU** on UE1, and 3.4 UU is 15–25 % wide (a slightly miniaturised world). M3 still measures; this only moves the starting default and names the source. Suggested change: `StereoIPD` default 2.85 with the 44.6 figure cited, `[reported]` until measured.
